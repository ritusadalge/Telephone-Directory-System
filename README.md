# 📞 Telephone Directory Maintenance System

A Java and MySQL based **Telephone Directory Maintenance System** developed as a DBMS minor project.

## 🚀 Features

- Department management
- Employee management
- Telephone directory management
- Telephone enquiry/search
- Automatic department codes starting from `1000`
- JDBC connectivity with MySQL

## 🛠️ Technologies

- Java
- MySQL
- JDBC
- MySQL Connector/J
- VS Code
- MySQL Workbench

## 🗄️ Database

The system uses three main tables:

- `Department`
- `Employee`
- `Telephone_Directory`

The database stores department, employee, and telephone information using relational database concepts and foreign keys.
